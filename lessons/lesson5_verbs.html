📝 第一步：動詞變位基本概念

西班牙文動詞會根據「誰做動作」而改變詞尾。這叫「動詞變位」（conjugación），是西班牙文最核心的文法。現在先學現在式（presente de indicativo）。

動詞類別：看「詞根」最後的字母

類別原形詞尾例子中文
第一類-artrabajar工作
第二類-ercomer吃
第三類-irvivir住
🎯 變位口訣：先找到詞根（拿掉 -ar/-er/-ir 的部分），再根據主詞加上對應的詞尾。
例：trabajar → 詞根 trabaj- + 詞尾
• yo trabajo（我工作）/ tú trabajas（你工作）/ él trabaja（他工作）

現在式變位表：規則動詞

第一類：-ar 動詞（以 hablar 為例）

主詞變位例句中文
yo（我）-oyo hablo我說話
tú（你）-astú hablas你說話
él/ella/usted（他/她/您）-aél habla他說話
nosotros/as（我們）-amosnosotros hablamos我們說話
ellos/ellas/ustedes（他們/她們/諸位）-anellos hablan他們說話

第二類：-er 動詞（以 comer 為例）

主詞變位例句中文
yo-oyo como我吃
tú-estú comes你吃
él/ella/usted-eella come她吃
nosotros/as-emosnosotros comemos我們吃
ellos/ellas/ustedes-enustedes comen諸位吃

第三類：-ir 動詞（以 vivir 為例）

主詞變位例句中文
yo-oyo vivo我住
tú-estú vives你住
él/ella/usted-eella vive她住
nosotros/as-imosnosotros vivimos我們住
ellos/ellas/ustedes-enellas viven她們住
💡 記憶口訣：
-ar：o, as, a, amos, an
-er：o, es, e, emos, en
-ir：o, es, e, imos, en
只有 nosotros（我們）那一欄不同：-ar 是 -amos，-er 是 -emos，-ir 是 -imos。

頻率副詞（Adverbios de Frecuencia）

西班牙文中文頻率強度例句
siempre總是★★★★★ 100%Siempre llego temprano.
casi siempre幾乎總是★★★★☆ 80%Casi siempre desayuno en casa.

nunca / jamás從不☆☆☆☆☆ 0%Nunca llego tarde.
💡 墨西哥口語："de vez en cuando" 比 "a veces" 更常聽到，意思一樣都是有時候。
De vez en cuando voy a la playa. → 我有時候會去海邊。

動詞 + 頻率 的經典排列

頻率副詞通常放在動詞前面：

結構例句中文
Siempre + 動詞Siempre como a las dos.我總是兩點吃飯。
動詞 + siempreVoy siempre a las dos.我兩點總是去（不常用）
A veces + 動詞A veces salgo los viernes.我有時候星期五出去。
Nunca + 動詞Nunca estudio los domingos.我星期日從不唸書。
🎯 考試重點：nunca 和 jamás 本身就是否定詞，句子中不需要再加 "no"。
• ✅ Nunca como carne.
• ❌ No como carne nunca.（錯！雙重否定。雖然墨西哥口語偶爾會這樣說，但文法上算錯）

⚡ 不規則動詞的常見模式

模式一：yo 加 -g-（很多動詞！）

tener → tengo / salir → salgo / venir → vengo / hacer → hago / poner → pongo / traer → traigo / oír → oigo / decir → digo

模式二：元音變化（e→ie, o→ue）

poder → puedo, puedes, puede / querer → quiero, quieres, quiere

模式三：完全變態（要硬背）

ser, estar, ir, dar, saber 找不到規律，直接背熟！

💡 saber vs conocer（兩個「知道/認識」的區別）
• Sé（saber）= 我知道（事實、資訊、技能）
　→ Sé hablar español.（我會說西班牙文。）
　→ Sé que es tarde.（我知道已經晚了。）
• Conozco（conocer）= 我認識（人、地方、經驗）
　→ Conozco a Juan.（我認識 Juan。）
　→ Conozco Guadalajara.（我去過瓜達拉哈拉。）

💬 對話練習 — 正式版（公司工作流，一個人一天）

Nelson: Buenos días, Sofía. ¿Ya llegó el reporte del cliente?

→ 早安，Sofía。客戶的報告到了嗎？


Sofía: Sí, lo recibo hace una hora. Siempre llega temprano.

→ 到了，我一個小時前收到的。總是很準時。


Nelson: Perfecto. ¿Qué tareas tenemos hoy?

→ 完美。我們今天有哪些任務？


Sofía: Primero, revisamos el presupuesto. Después, preparemos la presentación para la reunión de las tres.

→ 首先，我們檢查預算。然後準備三點會議的簡報。


Nelson: Entendido. ¿A qué hora almorzamos?

→ 了解。我們幾點吃午餐？


Sofía: Casi siempre como a la una. Pero si tenemos mucho trabajo a veces como a la una y media.

→ 我幾乎總是一點吃。但如果有很多工作，有時候一點半吃。


Nelson: Ya veo. ¿Y después del trabajo? ¿Sales con tus amigas?

→ 原來如此。下班後呢？你會跟朋友出去嗎？


Sofía: Rara vez. Normalmente llego a casa, cocino algo rápido, leo un rato, y después me duermo temprano.

→ 很少。通常我回家、煮點東西、讀一會書，然後很早就睡了。


Nelson: Suena bien. Yo todavía no conozco bien la ciudad. ¿Me puedes enseñar buenos restaurantes algún día?

→ 聽起來不錯。我還不太熟悉這個城市。改天可以帶我去好餐廳嗎？


Sofía: ¡Claro que sí! Conozco varios lugares buenos. Mañana no trabajamos hasta tarde. ¿Te late ir después de cenar?

→ 當然可以！我知道好幾個好地方。明天我們不需要工作到很晚。吃過晚餐後去怎麼樣？


Nelson: Me late. Nos vemos mañana.

→ 可以啊。明天見。

西班牙文中文用法說明

preparar準備-ar 規則動詞
¿A qué hora...?幾點...？問時間經典句型
almorzar吃午餐不規則（o→ue）：yo almuerzo
Normalmente + 動詞通常...比 frecuentemente 更常用
